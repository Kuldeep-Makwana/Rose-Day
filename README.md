# 🌹 Rose Day Special Website

A romantic and interactive mini-website created to celebrate **Rose Day** 💐❤️
Beautiful falling rose petals, soft background, a lovely message, and a special card with DP — everything to make someone feel truly special ✨💞

## 🌟 Features

* 🌹 **Falling rose petals animation**
* 🌄 Beautiful romantic **background image**
* 💌 “**Read More**” button that opens a heartfelt message
* 🃏 A lovely **card with profile picture** (DP)
* 💖 Smooth animations and clean UI
* 📱 Works on all modern browsers
* 🎨 Designed using HTML + CSS + JavaScript only

## 🚀 How It Works

1. Open **index.html**
2. Beautiful **rose petals start falling automatically** 🌹✨
3. Click **Read More**
4. You’ll see a **romantic message** with a **special card + DP** 💖
5. Perfect for sending to your crush, partner, or friend on Rose Day 🌹❤️

## 📚 How to Run

Just download or clone the project and open `index.html`.

```bash
git clone https://github.com/Kuldeep-Makwana/rose-day-special.git
```
